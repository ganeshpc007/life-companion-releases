# Life Companion — downloads

Installers and the in-app update feed for **Life Companion**, a privacy-first companion that helps you build healthy work habits with gentle, well-timed reminders.

## Install

Open the [latest release](https://github.com/ganeshpc007/life-companion-releases/releases/latest) and download:

| Platform | File |
| --- | --- |
| macOS (Apple Silicon) | `Life-Companion_<version>_aarch64.dmg` |
| Windows 10/11 | `Life-Companion_<version>_x64-setup.exe` |

**macOS:** open the `.dmg` and drag Life Companion into **Applications** (in-app updates only work from there). The first time, macOS may say the developer can't be verified: open **System Settings → Privacy & Security → Open Anyway**.

**Windows:** if SmartScreen shows "Windows protected your PC", choose **More info → Run anyway**.

## Updates

After the first install, Life Companion checks for updates itself and offers **Update now**. You don't need to come back here.

This repository only hosts release files; the source code is private.
